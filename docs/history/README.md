# Historical development evidence

These reports, reviews, status matrices and aggregate metrics record earlier
WristPrompt development and acceptance checkpoints. Their test counts and pending
states belong to their original dates; they are not current release claims.
Only relative links/path references have been adjusted during organization.

Current product status belongs in the [README](../../README.md),
[changelog](../../CHANGELOG.md), [handoff](../CODEX_HANDOFF.md) and
[final acceptance](../D7_G_ACCEPTANCE.md).

Browse this directory for Day 1–5 reports and historical auth, refresh, billing and
emulator investigations. Active test references live one level up in `docs/`.
