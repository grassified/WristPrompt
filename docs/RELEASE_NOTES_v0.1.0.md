# WristPrompt v0.1.0

Early-access **source/developer release — READY WITH NON-BLOCKING DEBT**.
Build a matched phone/watch pair locally using the development guide. GitHub source
archives are the release artifacts; no debug or unsigned APK is offered as a
production installable binary.

Native Wear OS chat with Continue with ChatGPT, explicit API-key billing,
watch-direct streaming and real Stop. Durable local history supports reopen,
continuation, rename and deletion. Phone-managed presets and Photo Picker library
sync to the watch; supported models accept text plus multiple images. Native
Thinking controls preserve exact provider values. API-key image generation and a
durable fullscreen zoom/pan viewer are implemented.

Owner core physical acceptance passed on Galaxy Watch 7 SM-L310 / API 36 and a
paired Android phone. Automated and emulator evidence remains separately recorded
in [final acceptance](D7_G_ACCEPTANCE.md); no universal-device or paid API-key
physical success claim.

Known non-blocking limits:

- [#1](https://github.com/grassified/WristPrompt/issues/1): structured table records
  absent on tested physical path; readable list fallback remains usable.
- [#11](https://github.com/grassified/WristPrompt/issues/11): optional live API-key
  generation verification blocked by unavailable owner key; synthetic generation,
  persistence and viewer acceptance passed. SIWC generation unsupported by design.
- ChatGPT-plan Thinking intentionally exposes Default only; API-key explicit effort
  has automated coverage but was not physically exercised.
- Sent input-image thumbnails absent from completed transcripts.
- No cloud chat sync; unsent drafts/streaming tokens are not durable. Background
  continuation is best effort. TalkBack and battery/runtime profiling unverified.

ChatGPT subscriptions do not include API credits; errors never switch billing paths.
GPL-3.0-only with the narrow exact-artifact/version linking exception; third-party
licenses remain intact. See [changelog](../CHANGELOG.md), [build setup](../DEVELOPMENT.md),
[privacy](../PRIVACY.md) and [security reporting](../SECURITY.md).
